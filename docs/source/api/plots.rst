diffpes.plots
=============

Matplotlib rendering of diffpes carriers: energy-momentum spectral cuts,
constant-energy momentum maps, projected band scatters, distribution
curves, shared-scale comparison panels, detector-plane images, densities
of states, and three-dimensional cube and band-surface views. Every
function ingests native diffpes types or physical axes and returns the
Matplotlib objects that it creates.
